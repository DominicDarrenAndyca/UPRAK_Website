Metodologi & Rumus Kalkulasi

// 01. PRODUKSI ENERGI (MWh)

Esolar = (P × 8760) × (Iin / 5)

Ecoal = (P × 8760) × 0.85

*8760 = Jam/tahun, 0.85 = Efisiensi kapasitas pembangkit

// 02. BIAYA BAHAN BAKAR & OPS

Costfuel = (E × 0.4) × Harga_BB

Reqcoal = E × 0.4

*0.4 = Konsumsi Batu Bara (Ton) per MWh

// 03. LCOE (BIAYA PER MWh)

LCOES = 78rb + (600 / Iin × 100)

LCOEC = (Costfuel + Ops) / E

*LCOE menentukan harga rata-rata energi per satuan produksi

// 04. PERSENTASE SELISIH

Diff = |(C - S) / C| × 100%

*Digunakan untuk menentukan efisiensi ekonomi antar wilayah
